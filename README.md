## হিসাবের মূল বিধি

- **বেতন নির্ধারণ (অনুচ্ছেদ ৫):** বর্তমান মূল বেতন − বর্তমান স্কেলের প্রারম্ভিক ধাপ
  = পার্থক্য; ২০২৬ স্কেলের প্রারম্ভিক ধাপ + পার্থক্য; যোগফলের সমান ধাপ থাকিলে ঐ ধাপে,
  না থাকিলে পরবর্তী উচ্চতর ধাপে।
- **অনুচ্ছেদ ৯(২):** নির্ধারণের পর ১ জুলাই ২০২৬ তারিখে ১টি বার্ষিক বেতনবৃদ্ধি।
- **পর্যায়ভিত্তিক প্রদান (অনুচ্ছেদ ১(৩)):**
  - ১ জুলাই ২০২৬ – ৩১ ডিসেম্বর ২০২৬ → বৃদ্ধির **৪০%** (১ম–৯ম গ্রেড) / **৫০%** (১০ম–২০তম)
  - ১ জানুয়ারি ২০২৭ – ৩০ জুন ২০২৭ → **৭০%** / **৭৫%**
  - ১ জুলাই ২০২৭ হইতে → **শতভাগ**, বার্ষিক ইনক্রিমেন্টসহ
- **ভাতাদি:** ৩১ ডিসেম্বর ২০২৭ পর্যন্ত ৩০ জুন ২০২৬ এর অঙ্কে; **১ জানুয়ারি ২০২৮**
  হইতে এই আদেশের নির্ধারিত হারে।
- **পেনশন (অনুচ্ছেদ ৮):** স্ল্যাবভিত্তিক ১০০%/৭৫%/৬৫%/৬০%/৫৫% বৃদ্ধি, ন্যূনতম ও
  সর্বোচ্চ সীমাসহ; পরম সর্বোচ্চ ৭০২০০ টাকা।

## গেজেটের উদাহরণ দিয়া যাচাই

```bash
npm run verify
```

স্ক্রিপ্টটি গেজেটের **উদাহরণ ১** (৯৩০০ → ২১৯০০) ও **উদাহরণ ২** (১৩৭৯০ → ২৬৩০০)
সহ পেনশন সারণির প্রতিটি স্ল্যাব যাচাই করে।

## স্থানীয়ভাবে চালানো

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # প্রোডাকশন বিল্ড
```

## Vercel-এ হোস্ট করা

1. রিপোজিটরিটি GitHub-এ পুশ করুন।
2. [vercel.com/new](https://vercel.com/new) এ গিয়া রিপোজিটরিটি Import করুন।
3. Framework Preset স্বয়ংক্রিয়ভাবে **Next.js** সনাক্ত হইবে — Root Directory `./`,
   Build Command `npm run build`। কোনও Environment Variable প্রয়োজন নাই।
4. **Deploy** চাপুন।
